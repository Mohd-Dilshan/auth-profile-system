# auth-profile-system
A full-stack web application that allows users to securely log in, manage their accounts, and update their profile information. Includes a fully functional frontend and backend with authentication and profile management.

## Quick setup

1. Install dependencies:

```bash
npm install
```

2. Copy `.env.example` to `.env` and set `MONGO_URI` and `JWT_SECRET`.

3. Start both backend and frontend with one command:

```bash
npm run dev
```

- Backend runs on port `5000` by default.
- Frontend is served statically on port `3000`.
